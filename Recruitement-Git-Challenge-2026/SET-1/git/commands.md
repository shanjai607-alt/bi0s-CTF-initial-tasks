# Git Commands Used

## git clone
Clones a remote repository to the local computer.

## git status
Shows the current branch and the state of tracked and untracked files.

## git add
Stages changes so they can be committed.

## git commit
Saves staged changes as a commit.

## git switch -c
Creates a new branch and switches to it.

## git branch
Lists the branches in the repository.

## git merge
Combines changes from one branch into another.

## git reset
Moves HEAD to another commit and can undo or unstage changes.

## git push
Uploads local commits to a remote repository.
